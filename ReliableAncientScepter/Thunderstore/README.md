# ReliableAncientScepter

Adds a (somewhat) reliable way to obtain Ancient Scepter. Requires all 3 DLCs.

* Void Camps have 50% chance (configurable) to spawn a new interactable that has one piece of the Scepter. Interactable drains 30 credits (configurable) from Void Camp pool.
* ![gem](https://raw.githubusercontent.com/viliger2/RoR2_SmallerMods/refs/heads/main/ReliableAncientScepter/Thunderstore/Gem.gif)
* Halcyonite Shrine has 50% chance (configurable) to replace one of the items with another piece of the Scepter.
* ![shaft](https://raw.githubusercontent.com/viliger2/RoR2_SmallerMods/refs/heads/main/ReliableAncientScepter/Thunderstore/Shaft.gif)
* You then reforge it from both pieces at Wandering CHEF.
* ![reforge](https://raw.githubusercontent.com/viliger2/RoR2_SmallerMods/refs/heads/main/ReliableAncientScepter/Thunderstore/Craft.gif)
