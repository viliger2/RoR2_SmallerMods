# CertainHallowedConcepts
Adds tweaks to Hallowed Concepts to make things more consistent with more player agency. Every tweak and number is configurable.

* Ancient Sepulcher
  * Giving flowers to Soul Conduits that are above 90% health advances holdout zone charge by 10%.
  * Finishing holdout zone with all 3 Soul Conduits alive gives guaranteed Reincarnation page.
  * Ancient Sepulcher has a guaranteed chance to spawn on one of the first four stages. Resets on loop. If one spawned naturally then it doesn't try to spawn it anymore.
* Ritual Gong
  * Portal from hitting (not using) Ritual Gong now spawns within 50 meters of hitter (tries to find nearest ground node). If no node is found then it is spawned where it is usually spawned (in front of the gong).
* Ritual Timer
  * Ritual timer is now extended by 5 seconds for each Hex cleansed.
